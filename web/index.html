    EMEA Q3 revenue: currency, not demand

    Verified 0.94

    Reported EMEA revenue fell 5.7% from $9,468,359 in Q2 2025 to $8,926,124 in Q3 S1. Measured in local currency the same book of business grew 2.2% S1, so currency accounts for 7.9 points of the decline S2.

    The euro weakened from 1.092 to 0.995 against the dollar between the two quarters S2. Separately, Helvetica Logistics, which was 9.5% of EMEA Q2 revenue, did not renew at the end of Q2 S3. An internal review attributes the non-renewal to the customer being acquired, not to a competitive loss S4.

    Limitation: attribution between currency and the lost account is arithmetic on reported figures, not a controlled comparison.

    How it works
    
        
    
          One agent, eight nodes, and a hard stop on everything it can spend.
        
    
        
      
          
    1. 1
      Plan
      Three to eight concrete steps, each naming the tools it intends to use and the evidence it expects to find.
      2. 
          
    2. 2
      Approve
      The graph interrupts. You approve, edit the steps, or cancel before any budget is spent.
      3. 
          
    3. 3
      Execute
      A tool-calling loop per step. Read-only SQL, hybrid document search, web search, exchange rates, a safe calculator.
      4. 
          
    4. 4
      Reflect
      Continue, re-plan with a stated reason, or stop early because the question is already answered.
      5. 
          
    5. 5
      Verify
      Every citation must exist and the numbers in each sentence must appear in the evidence. Unsupported claims are removed.
      6. 
          
    6. 6
      Resume
      Every transition is checkpointed. Kill the worker mid-run and it resumes without repeating a single tool call.

    Built for trust
    
        
    
          An agent that writes its own SQL and chooses its own tools needs guardrails that do not
          depend on the model behaving.
        
    
        
    
          
    
            
    Read-only SQL, by parsing
    
            
    
              Statements are parsed with sqlglot and reasoned about as a syntax tree. A regex cannot
              tell a CTE named delete_me or the literal 'DROP TABLE' from
              a real mutation. The database is also opened query_only, on its own
              engine, because a parser is software too.
            
    
          
    
          
    
            
    Citations checked against numbers
    
            
    
              The realistic failure is not an invented [S9]; it is a real source id
              attached to a figure the model made up. Numeric claims are matched against the cited
              rows, allowing for rounding and unit changes.
            
    
          
    
          
    
            
    Four hard budgets
    
            
    
              Steps, tokens, cost and wall time. A step cap alone is no cost control when one step
              can call a tool fifty times. A model missing from the price table costs a fallback
              rate, never zero.
            
    
          
    
          
    
            
    Untrusted tool results
    
            
    
              Documents and web pages are data, never instructions. The seeded corpus contains a
              realistic injection attempt; ingest trips eight signatures on it and none on the
              other eleven documents.

      Questions
      
        
      
          
      
            Does it need an API key?
            
      
              No. The default configuration uses a deterministic scripted model, recorded tool
              fixtures and offline hash embeddings, so the whole application and its 95 tests run
              with no network access and no key. Point OPENAI_BASE_URL at Groq or a
              local Ollama to use a real model.
            
      
          
      
          
      
            What stops the agent writing to the database?
            
      
              Three things. Statements are parsed and anything that is not a read is refused with a
              reason. The allowlist limits which tables and columns can be named at all. And the
              company data lives in a separate database opened read-only, so the agent's connection
              has no write capability to grant.
            
      
          
      
          
      
            What happens if the worker crashes mid-run?
            
      
              Every node transition is checkpointed, and every tool call is recorded in a ledger
              keyed by a hash of run, step, tool and canonical arguments with a uniqueness
              constraint. A resumed run replays recorded results instead of calling out again, so
              recovery costs nothing and repeats no side effects. The schema and the design are in
              place; the worker itself is the next phase.
            
      
          
      
          
      
            Is the demo data real?
            
      
              It is generated, seeded and reproducible — two years of a fictional company,
              containing three deliberate stories so there is something genuine to find. Every
              figure in the example report above is computed from those rows, not written into a
              fixture.
